To-Do List App

A simple frontend-only web app built with HTML, CSS, and JavaScript that lets you add and delete tasks. Perfect for beginners learning DOM manipulation and interactivity.

📂 Folder Structure
todo-app/
│
├── index.html       # Main HTML file
├── css/
│   └── style.css    # Styling
├── js/
│   └── script.js    # JavaScript logic
└── assets/
    └── images/      # Optional images

🛠️ Technologies Used

HTML – Structure of the page

CSS – Styling and layout

JavaScript – Adds interactivity (add/delete tasks)

⚡ How It Works

User types a task in the input box.

Clicks Add Task → JS creates a new task in the list.

Each task has a Delete button to remove it.

CSS styles the list and buttons for a clean look.


💡 Why This App Is Useful

Helps beginners practice DOM manipulation.

Demonstrates interactive frontend development.

Serves as a foundation for larger projects like note-taking apps or task managers.
